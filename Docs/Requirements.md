# Requirements

## Mục tiêu
Thiết lập project kiểm thử tự động với Selenium WebDriver, NUnit, và Allure Report cho trang web Văn phòng điện tử UTC (https://vanphongdientu.utc.edu.vn/Login).

## Phạm vi kiểm thử
- Functional testing (Đăng nhập, CAPTCHA, Quên mật khẩu)
- Security testing (SQL Injection cơ bản vào form đăng nhập)
- Performance testing (Response Time, Load, Stress) - Sử dụng công cụ bên ngoài (JMeter)

## Yêu cầu kỹ thuật
- Sử dụng Page Object Model
- Tích hợp Allure Report
- Mã nguồn quản lý bằng Git
- Không hardcode credentials
